# Holy Grail Layout

Projeto desenvolvido com HTML e CSS para implementar um layout responsivo no padrão "Holy Grail".

Esta atividade faz parte da pós-graduação em Desenvolvimento Web.

## Tecnologias

- HTML5
- CSS3 (Flexbox)

## Observação

Projeto criado com base no repositório disponibilizado pelo professor Rui Pimentel, disponível em: https://github.com/utfpr-cefwm/html5-boilerplate-2026-1
